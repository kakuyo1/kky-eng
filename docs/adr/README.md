# ADR

重大取舍记在这里。`AGENTS.md` / `PRODUCT.md` / `TODO.md` 三处指过来的是本目录。

**编号**：四位序号 + 短横线标题，`NNNN-短横线标题.md`（如 `0001-mouse-hook-own-thread.md`）。
新增时取目录里已有最大号加一，不复用、不重排。

**模板**：

```markdown
# NNNN 决定的短标题

- **状态**：accepted ｜ proposed ｜ deprecated ｜ superseded by ADR-NNNN
- **背景**：什么处境逼出了这个决定。
- **决定**：选了什么。
- **后果**：要接受的代价、被排除的选项、已知的边界。
```

四栏按需取舍：短的一两句话就能说清时，写一段话即可——ADR 的价值在记下 “做过这个决定、为什么”，
不在把四栏填满。**后果**只在有非显然的下游影响时才写，**背景**只在读者缺了它就看不懂时才写。

**何时写**：同时满足三条才记——改动代价大（回头难）、无上下文会让人困惑（读者会问 “为什么是这样”）、
确有替代方案且是为特定理由选中的。三条缺一就别写：容易改的直接改就是了。
