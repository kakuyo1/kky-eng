# 0019 词源不进解释缓存键

- **状态**：accepted
- **背景**：词源是单词解释的一项可选附加内容，由设置开关控制，而要它就得付输出 token。缓存条目按 “解释语言 + 多义开关 + lemma” 存；词源若也进键，同一份释义会因为一个纯显示的开关再买一次。
- **决定**：缓存键保持三样不变，词源作为条目里的一个字段随释义一起存。开关只作用于两处：发请求时决定提示词里留不留词源句，画卡片时决定画不画。
- **后果**：关闭状态下抓过的词，条目里没有词源，此后打开开关也不会补上——补要重新付费，而那正是这条规则要避免的。要让这些词长出词源，只能由读者显式再请求一次（`reviewWord` 那条 “现在解释” 的路子就是这种形状），不能靠开关自己回头去买。被排除的另一条路是永远索要词源、把它当必填字段：实现更简单，但读者关掉它之后每次取词仍要为它付费。
