# 0008 选区只由拖选触发

- **状态**：accepted
- **日期**：2026-10-05
- **背景**：低层鼠标钩子把双击与三击也当作选区完成。Windows 的双击本来就是常见的文本操作，读者在编辑器、浏览器和文档中频繁双击时，Lens 会随之打开选区动作条；三击还可能在同一串点击中再次触发。系统双击时间和双击范围越宽，这种打扰越明显。
- **决定**：选区入口只接受按下到松开期间越过系统 `SM_CXDRAG` / `SM_CYDRAG` 阈值的拖拽。单击、双击、三击以及阈值内抖动都不触发 `selectionReleased`。
- **理由**：拖选是明确表达“我要处理这段文字”的动作，双击和三击则同时承担编辑器中的普通语义。收窄入口直接减少动作条出现次数，不需要改变气泡倒计时、缓存或已知词语义，也不把一个新的策略开关引入设置面板。
- **后果**：单词查词仍可用，但读者需要拖过单词；旧的“双击选词、三击选段”快捷入口不再触发 Lens。手势判定保持为无副作用的纯函数，边界测试继续覆盖系统拖拽阈值和反向拖动。
