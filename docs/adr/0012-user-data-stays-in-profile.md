# 0012 用户数据留在用户目录，不进入安装目录

- **状态**：accepted
- **背景**：阶段二草案曾提出把设置、known-set、缓存和历史放到安装目录，但 `settings.json` 同时承载 API key；安装目录可能只读，也可能被多个用户共享。
- **决定**：阶段二继续使用 `%APPDATA%\Lens\settings.json` 作为读者数据目录。设置、known-set、缓存、历史与 API key 共用这一份文档；安装目录只放程序和随包分发的静态数据。卸载不删除该目录，重装复用其中的数据。
- **后果**：不做安装目录数据迁移，也不把密钥拆到安装目录之外；用户数据与程序升级、安装路径和用户安装方式解耦。`PHASE2.md §5.1` 的 “用户安装目录” 解释为用户数据目录，而不是程序安装目录。
