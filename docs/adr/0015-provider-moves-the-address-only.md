# 0015 服务商只改地址，模型由读者手填

- **状态**：accepted
- **背景**：阶段二的模型服务是一对数据驱动的目录项：每个服务商带 `defaultModel` 与 `models`，设置里选服务商就同时
  改地址和模型。实际用起来两处都不成立——目录里的模型名一夜间就过时（服务商改名、加型号、读者另有自家网关），
  而默认模型被静默写进设置文档，读者换成自己的服务商后拿到的是一个账号里根本不存在的模型名；地址同理，
  没有任何机制保证目录里那几个 base URL 跟得上服务商。
- **决定**：目录只保留服务商的 label / 分组 / base URL / 请求覆盖项；服务商这一项只改服务地址，模型改成手填
  输入框，不预填、不跟随服务商。地址旁写明这是常见地址、可能失效，以其官方文档为准。
- **后果**：换服务商后要自己确认模型名（模型服务页因此多一行提示，且不再有 “Custom 才能手填” 这条分支）；
  价目表按模型名查，手填出表外的模型金额记 0 并在页面上写 “未列出价格”；`catalog.json` 的 `defaultModel` /
  `models` 随之下架，加载器不再校验 “默认模型属于模型列表”，首装默认模型仍由 `main.cpp` 的兜底值给出。
