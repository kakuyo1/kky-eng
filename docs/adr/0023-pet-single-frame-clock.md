# 0023 宠物的帧由单一计时器推进，不用 AnimatedSprite，不引入游戏引擎

- **状态**：accepted
- **背景**：宠物有身体、表情、特效、配饰等多个图层，它们必须在同一帧显示。`AnimatedSprite` 每个实例各自计时，多图层会错帧。
- **决定**：`PetController` 用一个 `QTimer` 推进帧索引，所有图层绑定同一个 `frameIndex`，窗口隐藏时停止计时器。帧率按每个动作的 `fps` 换算。不引入 Unity、Godot 或 Spine，也不写自定义 Scene Graph 节点；只有性能分析证明有瓶颈时，才考虑 `QQuickItem`。
- **后果**：窗口可见时，计时器约每 20 ms 唤醒一次，即每秒 50 次。这是为了让 1–12 fps 的动画按节拍切换。若性能不够，先调整 tick 长度，不换方案。动作切换只由状态机决定，QML 层不得自行播放或停止动画。
