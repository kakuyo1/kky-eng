# 0021 桌面宠物是独立窗口，排除抓屏，纯逻辑留在 core

- **状态**：accepted
- **背景**：宠物要常驻桌面并持续播放动画。若画在解释浮层或设置窗口里，它会随那些表面显隐；若被截进画面，自动扫描的像素比较会每秒都判定 “屏幕在变”，持续触发 OCR。
- **决定**：宠物是独立的透明、无边框、置顶窗口，作为一个独立的 QML 窗口，按 `docs/adr/0002` 的 “按窗口拆分” 放置；不抢焦点、不进任务栏。窗口设置 `WDA_EXCLUDEFROMCAPTURE`，截图与扫描都看不见它。动作选择、配饰互斥与配置校验放在 `src/core/pet/`，不依赖 Qt，由 `lens_gtest_unit` 离线测试；Qt 外壳留在 `src/app/pet/`。
- **后果**：
  - 与选区钩子的隔离不需要新代码。宠物与应用同进程，钩子的 `overOurWindow` 已经排除 “按下点落在本进程窗口上” 的拖拽。若宠物以后拆到别的进程，这条隔离失效，需要重新处理。
  - 鼠标穿透用原生 `WS_EX_TRANSPARENT` 切换，不用 `Qt::WindowTransparentForInput`。后者在运行时切换后会隐藏窗口，这一条来自搜索摘要，未在官方文档核实。原生路径能否在各 Windows 版本上生效，要真机验证。
  - 排除抓屏要求 Windows 10 2004 及以上。更低版本上设置失败，宠物会出现在截图里，启动时会记一条警告。
